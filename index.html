What is learned, and what is supplied?

Labelled calibration learns source waveform templates and sensor likelihoods. Source signs, their identities, the three-unit chain, global sign symmetry and Bayesian inference are supplied. Relation sensors measure pair products, an engineered interferometric contrast. This is a small inverse-inference reference model, not a simulation of biological action potentials or a port of PerceptionLab's wave tank.

Python uses two synchronous sum-product rounds. The browser uses the equivalent closed-form equations for this symmetric chain, checked against Python and exact eight-world enumeration. A mean waveform hides uncertainty; the alternative-world panel preserves it. Full results, failures and boundaries are in the protocol.

Antti Luode's research direction · 16 November 2026. This project tests a proposed structure of shared prediction. It does not establish subjective experience, intrinsic meaning, or an advantage over ordinary Bayesian inference. Runs locally from these files without a server or network.
