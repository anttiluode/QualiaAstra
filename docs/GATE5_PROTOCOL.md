# Gate 5 frozen protocol — evidence, echo and provenance

Written **16 November 2026**, before independent-seed confirmation. Follows Gate 4's learned-wiring result and Claude's matched-latch chain study. **No Gate 4 results or code are changed.**

## Question

When the same signed message "B is positive" may be either a *new B sensor measurement* or an *internally generated prediction of B*, does the sender/receiver need explicit evidence provenance to prevent counting its own prediction as independent confirmation?

This isolates an **information-accounting mechanism**, not autonomous learning of which signal is a real sensory event. Here the provenance flag is *provided* and the correct inference algebra is supplied. The source of such a flag in a physical dendritic circuit is an open problem.

## Synthetic Markov world

A, B and C are signed ±1 events in a Markov chain. A is equiprobable. B copies A with probability 0.85, C copies B with probability 0.85. True transition correlations are thus rho1=rho2=0.70. During calibration the learner receives 512 independent *fully observed* A/B/C episodes (no relation classes, teacher weights or network topology hidden at this gate). Two one-tap correlations, E[A B] and E[B C], are estimated from this data. This is **observational supervised parameter estimation**, not Gate 3's unlabelled factor learning.

Each independent test event has:
- A actually sensed perfectly; C and B true signs are hidden from inference.
- A subsequent B-like report z∈{−1,+1} and a reported reliability p∈{0.55,0.70,0.85,0.95} (equiprobable).
- Equally likely **ACTUAL**: z is an independent noisy observation of the real B, P(z=B)=p; or **REPLAY**: z=A is generated by the model itself, carrying *no independent evidence* about B, regardless of the accompanying apparent p.

During test only A, z, p and provenance are available to the provenance-aware learner. The truth B and C is used exclusively for scoring. This generator deliberately permits **indistinguishable inputs** without provenance, especially z=A.

## Shared Bayesian model

Let m=rho1*A and k=2p−1. A genuine B observation updates the expected B by:

    m_B=(m+k z)/(1+m k z)

and propagates m_C=rho2*m_B. On REPLAY, m_B=m: the imagined report is not a new observation. A cut of B→C forces a zero C prediction without altering the B state. An exact reference uses the true rho values; the learner uses the two observationally estimated correlations. Repeating REPLAY any number of times must leave m_B and m_C unchanged; the naive repeated-likelihood control should show false confidence.

## Comparators

1. **Evidence-aware:** estimate rho1 and rho2 from full calibration; respect ACTUAL vs REPLAY tags.
2. **Echo-naive:** same learned rho1 and rho2, same raw reports and p values, always treat the report as a new ACTUAL measurement.
3. **Echo-blind optimal:** same learned rho values and raw report/p but NO mode/provenance. Marginalize the unknown mode with the known 50:50 prior. When z=A, actual is possible alongside replay; posterior P(ACTUAL|A,z,p) is computed by Bayes. When z≠A, replay is impossible and the report must be actual. This is the information-theoretic comparison, not a deliberately weak straw man.
4. **Exact provenance-aware Bayes reference:** same tag but known true correlations (0.7/0.7), in place of learned correlations.
5. **Scrambled provenance:** same evidence-aware algorithm but tags cyclically shifted between unrelated test episodes; destroys reliability of event origin while preserving marginal tag frequency.
6. **Ignore B:** keep A's prior expectation, never incorporate a B-like report; tests a network that refuses new evidence.
7. **Cut B→C:** force C prediction to zero even though A and B states still exist.

The **provenance-aware learner receives strictly more information** (a provenance tag) than the echo-blind control. We must NOT call this equal-information model superiority. This is an ablation of a required input variable, with a separate Bayes-optimal no-tag control to prove its identifiability limit.

## Scoring and frozen evaluation

Main metric: relative squared error on the held-out signed **C** event, (C−m_C)^2, normalized by predicting zero (which has error 1). Additionally report replay-only and actual-only MSE, and the B state; this is a simplified signed-event gate, not raw-waveform reconstruction.

Six development seeds 17001..17006 were examined when choosing the protocol and thresholds. They are **not** confirmation results and must not be used as evidence of general performance.

**Independent confirmation:** twelve training seeds 750001..750012 (512 calibration episodes), corresponding test seeds 850001..850012 (4096 separate test episodes each). No hyperparameter/threshold changes after running those seeds.

PASS requires ALL:
- Within **0.020 absolute MSE** of the known-parameter exact provenance-aware Bayes reference on at least 10/12 populations.
- Learned evidence-aware MSE at least **0.005 lower than naive repeated-observation inference** on at least 10/12.
- Learned evidence-aware MSE at least **0.001 lower than the optimal no-provenance mixture** on at least 10/12.
- Shuffling provenance produces MSE at least **0.010 worse than evidence-aware** on at least 10/12.
- All 12 populations pass deterministic causal checks: repeated replay does not increase confidence, a reliable contradictory actual observation can change B/C sign, replay cannot, B→C cut removes C but not B, test B/C truth corruption does not alter predictions, and an ACTUAL/REPLAY matched-input pair yields different posteriors.

Even all passes would establish only that *origin metadata is useful and cannot always be inferred from an otherwise identical value*, a basic statistical fact. It would NOT establish how neurons acquire provenance, qualia, nonlinear dendritic cancellation, automatic wiring, or any improvement beyond correct Bayes.
